# Kotkantien Maalaus ja Tapetointi

Verkkosivusto Kotkantien Maalaus ja Tapetointi -yritykselle. Sivusto esittelee yrityksen tarjoamat maalaus- ja tapetointipalvelut, yrityksen tiedot sekä tarjoaa yhteydenottolomakkeen.

## Ominaisuudet

- Moderni ja responsiivinen käyttöliittymä
- Sujuva siirtyminen osioiden välillä (Smooth Scroll)
- Yhteydenottolomake validaatiolla
- Font Awesome -ikonit yhteystiedoissa

## Käytetyt teknologiat

- HTML5
- CSS3
- JavaScript
- Font Awesome
